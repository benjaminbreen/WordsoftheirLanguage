# julg1847_oldworld
Source: Vater/Jülg, Litteratur der Grammatiken (1847), IA litteraturdergr00jlgoog (djvu OCR). 1815 ed. not used.
Method: headings detected from Sachregister names; entries = blank-separated blocks; manual heading->glottocode map for Africa/Asia/Oceania/Siberia; Glottolog check = author surname + year±2.
Counts: 1409 in-scope rows in _all.csv; yes 77, no 733, no glottocode 439, compendium (Mithridates/Balbi/Klaproth etc.) 125, unclear 35.
Problems: OCR poor; heading detection misses many headings, so some rows are assigned to the wrong language (e.g. Amharic under 'Amboina', Mongol under 'Mokoby'). Treat in_glottolog as rough. Bibliography almost entirely printed: only ~6 manuscript mentions in the whole book, none in scope apart from Minutoli's Siwi list from a Siwa informant's MS (printed 1827; Minutoli is in Glottolog).
Orphans hand-picked (10) from small/thin languages; most web checks not done.
